# Agent-Reach

This is a pointer to the real Agent-Reach skill maintained at:
https://github.com/Panniantong/Agent-Reach

## Install
```bash
npx skills add Panniantong/Agent-Reach@agent-reach
```

## What it does
Agent-Reach gives Hermes the ability to read and search the internet:
- Web search (general)
- YouTube transcripts and search
- Twitter/X posts and profiles
- Reddit threads and subreddits
- GitHub repositories and files
- RSS feeds
- Bilibili and XiaoHongShu

All zero API fees. The CLI is installed locally and Hermes invokes it automatically when research is needed.

## Security
Read-only external access. No credentials required for most sources. Low risk.

## Usage
Once installed, Hermes will automatically use Agent-Reach when asked to research, search, or read internet content.
