# GLOSSARY

Key terms, people, and project names used in this system.
Update when new terms, people, or projects are introduced.

## Terms

| Term | Definition |
|---|---|
| AAR | After-Action Review. Weekly structured reflection using Intended / Actual / Sustain / Improve. |
| Agent-Log | Machine-readable log of every automated action taken in the system. |
| Canonical Memory | Approved, stable knowledge that shapes future agent behavior. |
| Ephemeral | Temporary work that should not shape future behavior by default. |
| INTAKE | The agent working zone. Files enter here before being routed. |
| Intent | The system's purpose, boundaries, and decision fallback rules. |
| OODA | Observe, Orient, Decide, Act. The loop every agent action follows. |
| Outbox | Staging area for agent output awaiting human approval before any external action. |
| PARA | Projects, Areas, Resources, Archive. Actionability-based organization framework. |
| Working Memory | Active context for current work. Retained while active, archived when complete. |
