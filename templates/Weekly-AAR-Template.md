# WEEKLY AAR TEMPLATE

## Why This Matters
A system does not stay clean because it was designed well.
It stays clean because it is reviewed, corrected, and tightened regularly.

## Template

# Weekly AAR
Week: [YYYY-WW]
Date Range: [Start Date] to [End Date]
Reviewer: [Human / Agent / Both]

## 1. Intended
What was the system supposed to accomplish this week?

## 2. Actual
What actually happened?

## 3. Sustain
What worked well and should be preserved?

## 4. Improve
What broke, drifted, or created unnecessary friction?

## 5. Truth Check
- Were any summaries treated as facts without evidence?
- Were any raw sources overwritten or obscured?
- Were any outputs promoted to memory too early?
- Where was uncertainty handled well or poorly?

## 6. Agent Performance
- Which agent or subagent performed well?
- Which one drifted or failed?
- Did any contract need tightening?
- Did any prompt produce bloated or weak output?

## 7. Folder Hygiene
- Any misfiled items?
- Any duplicate notes or assets?
- Any stale projects or inactive working memory?
- Any naming inconsistencies?
