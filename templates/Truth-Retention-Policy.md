# TRUTH RETENTION POLICY

## Core Principle
Not everything should become memory.
Most agent output should remain temporary until reviewed.
Retention must favor truth, provenance, and reversibility over convenience.

## Truth Hierarchy
1. Original files and raw inputs
2. Human-authored notes
3. Verified logs and records
4. Approved summaries
5. Derived insights and interpretations
6. Draft agent outputs

## Retention Classes

### Ephemeral
Temporary work that should not shape future behavior by default.

### Working Memory
Current context needed to advance active work.

### Canonical Memory
Stable knowledge that should inform future work.

## Promotion Rules
Only promote material to canonical memory if it has traceable sources, no unresolved critical uncertainty, and human or defined-process approval.

## Required Metadata for Important Agent Outputs
- Source files used
- Assumptions made
- Open uncertainties
- Date created
- Responsible agent or human
- Recommended next action

## Rewrite Rules
Agents may append, draft, suggest, and create files in approved output zones.
Agents may not overwrite original evidence, replace human notes without approval, collapse raw sources into a summary and delete the source, or promote low-confidence material into canonical memory automatically.

## Weekly Review Questions
- What was added to memory this week?
- What should remain temporary?
- What was promoted too early?
- What needs stronger evidence?
- What should be archived?

## Default Rule
When in doubt, keep the item temporary, preserve the source, and escalate for review.
